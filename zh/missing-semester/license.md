# 许可协议

本课程的所有内容，包括网站源代码、讲义、练习和讲座视频，均采用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 许可协议。

这意味着你拥有以下自由：

- **分享** — 以任何媒介或格式复制和再分发本材料
- **改编** — 对材料进行混编、变换和基于此创作

在下列条件下：

- **署名** — 你必须提供适当的感谢，附上许可协议链接，并说明是否进行了修改。你可以任何合理的方式执行上述要求，但不得以任何方式暗示许可方认可你或你的使用。
- **非商用** — 不得将本材料用于商业目的。
- **相同方式共享** — 如果你混编、变换或基于本材料进行创作，你必须以与原作相同的许可协议来分发你的贡献。

这是 [正式许可协议](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode) 的通俗易懂摘要（并非替代品）。

## 贡献指南

你可以通过在我们的 GitHub [仓库](https://github.com/missing-semester/missing-semester) 提交 issue 和 pull request 来对课程内容进行纠错和提出建议。这包括讲座视频的字幕，它们也在该仓库中（参见[这里](https://github.com/missing-semester/missing-semester/tree/master/static/files/subtitles/2020)）。

## 翻译指南

只要遵守许可协议的条款，你可以自由翻译讲义和练习。
如果你的翻译版本保留了课程的结构，请联系我们将你的翻译版本从我们的页面进行链接。

翻译讲座字幕时，请通过在 YouTube 上以社区贡献的方式提交你的翻译。
